## 三、T3 — C2「银行对账单字段赋值」（GUI，~8 case）

入口：场景管理 → 新增/编辑「银行对账单字段赋值」场景。

- [ ] M3.1 **多条件 AND**：一个账单类型分组内点行尾「新增」→ 当前行下方插入**空白**条件行，子序号 `#1.1 / #1.2`；可加多条，逻辑为 AND（同时满足）
- [ ] M3.2 **新增账单类型 vs 新增条件区分**：顶部「+新增账单类型」→ 新分组 `#2`；行内「新增」→ 同分组加条件。两者语义不同
- [ ] M3.3 **删除**：「×」删单个条件（删到分组最后 1 条保留空占位）；「删除该类型」删整个分组，可删到 0 个类型（保存时校验提示"至少 1 行"）
- [ ] M3.4 **FundType 下拉**：条件行字段选 `FundType` → 值变**单选下拉**，选项 = `assets/FundType枚举值.xlsx`（Inbound/outbound/…）且**顺序一致**；选 `Currency` 等其它字段 → 值仍是文本框
- [ ] M3.5 **赋值行下拉**：底部「赋值」行字段选 `FundType` → 写入值也变下拉（同 M3.4）
- [ ] M3.6 **对账字段可空**：对账字段可删到 0 行；保存不报错（引擎走无条件赋值）。填了的行两端字段必填（留一端空 → 保存提示报错）
- [ ] M3.7 **老数据迁移**：打开一个**v2.1.10 及更早创建的**旧 C2 场景（单条件）→ 正常显示为单条件分组（`#1.1`），可正常编辑/保存，不报错、不丢配置
- [ ] M3.8 **端到端赋值**：配置好 C2（多条件 AND + FundType 赋值）→ 导入银行对账单跑场景 → 命中行的目标字段被正确赋值（抽查几行；与预期一致）
- [ ] M3.9 **FundType 文件缺失降级**（可选）：临时移走 `FundType枚举值.xlsx` 重启 → 字段选 FundType 时值回退文本框 + 一次性提示，不崩溃

## 四、T2 — pending 月度移除核对（GUI，~8 case）

入口：月度 Pending 数据核对模块。

- [ ] M4.1 **导入后弹提醒**：导入某月 pending 数据成功后，弹"是否核对移除pending数据？"
- [ ] M4.2 **选「否」零变化**：选否 → 流程与旧版完全一致（无新行为）
- [ ] M4.3 **选「是」导入移除文件**：选是 → 文件选择器 → 选 `移除归档Pending账单.xlsx`（可多选）→ 提示导入成功（入库行数）
- [ ] M4.4 **同月重导覆盖**：对同月再导入移除文件 → 旧数据被替换（不累积）
- [ ] M4.5 **表头不符报错**：选一个**非移除模板**的 xlsx → 报错（表头不符），不入库脏数据
- [ ] M4.6 **对账后自动匹配**：跑对账（上月 vs 本月，上月 = 导入移除文件的月）→ 对账完成；missing 行自动与移除数据匹配（结果用于导出）
- [ ] M4.7 **导出 sheetA**：导出该 run（single run）→ 最右侧出现 sheet「missing核对移除」，含 missing 行 + 末列「移除核对状态」（值 `已匹配移除` / `missing有_移除无`），抽查标记正确
- [ ] M4.8 **导出 sheetB**：若存在"移除有、missing 无"的记录 → 出现 sheet「移除有_missing无」，列为移除文件原始字段；若不存在则无此 sheet
- [ ] M4.9 **未导入移除文件时**：未导入移除文件直接对账 + 导出 → 无新增 sheet（导出与旧版一致）
