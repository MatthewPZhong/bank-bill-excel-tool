## 二、Bug 1 验证用例：多币种勾选框不可点击

### 根因回顾

外层 `<label class="new-account-field">` 隐式关联了币种文本输入框（第一个 labelable 后代），点击 checkbox 时事件冒泡到外层 label，触发其 activation behavior 将焦点转发到币种输入框，导致 checkbox 状态被回滚。

### 修复方案

将所有 `<label class="new-account-field">` 改为 `<div class="new-account-field">`，消除 label 隐式关联行为。

## 三、Bug 2 验证用例：新增行币种输入框重复

### 根因回顾

`addNewAccountRow` 使用 `cloneNode(true)` 深拷贝首行，克隆了已被 `ensureCurrencyGhostShell` 改造的 DOM 结构。ghost input 携带了 `.new-account-currency-input` class，导致 `querySelector` 优先选中 ghost input 而非真实 input。后续 `ensureCurrencyGhostShell` 给 ghost input 添加了 `enum-active-input` class，使其脱离绝对定位变为可见，表现为两个输入框。

### 修复方案

在 `addNewAccountRow` 的 `cloneNode(true)` 之后、`initializeNewAccountRow` 之前，清理克隆行中的 `.enum-input-shell` 结构（移除 shell 和 ghost input，将真实 input 还原到原始位置），让 `initializeNewAccountRow` 从零重建 ghost shell。
