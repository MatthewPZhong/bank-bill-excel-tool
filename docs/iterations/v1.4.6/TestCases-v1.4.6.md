**文件 A — 标准数据（`test-bank-accounts-standard.xlsx`）：**

| 账户性质 | 账户状态 | 是否参与对账 | 银行账号 | 币种 |
|---------|---------|------------|---------|------|
| 客资 | 正常 | 是 | 1234567890 | CNY |
| 客资 | 正常 | 是 | 1234567890 | USD |
| 客资 | 正常 | 是 | 9876543210 | HKD |
| 自有 | 正常 | 是 | 5555555555 | CNY |
| 自有 | 正常 | 是 | 5555555555 | EUR |

只有"银行账号"和"币种"列，缺少"账户性质"等列。

**文件 C — 空数据（`test-bank-accounts-empty.xlsx`）：**
有完整表头但无数据行。
