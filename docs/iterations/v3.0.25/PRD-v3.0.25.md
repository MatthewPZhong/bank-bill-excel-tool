## 2. 设置弹窗与存档契约

- 设置页底部统一为【确认】。存档设置有修改时保存保留期限后关闭，无修改直接关闭，失败时保留弹窗并恢复按钮。
- 右上角关闭和存档设置返回箭头不保存；在途设置加载使用请求代次隔离，旧响应不得覆盖重新打开后的状态。
- 自动更新已下载时，自动更新页仍显示【稍后】；存档中心与存档设置页显示【确认】。
- 存档保留期支持 30、60、90、180、365 天和永久；缺失或非法配置按 60 天，既有合法值保持不变。
- 网银模板“不存档”在 UI、IPC、控制器和网银/月度余额运行时全部退役；旧排除配置启动后统一为 `[]`。
- operation tracker 通用 `skipArchive` 能力保留，存档文件结构、批次、Blob 去重、打开、另存、锁定、删除和重试契约不变。

## 3. 文案与视觉契约

- 删除自动更新和存档中心三段指定说明，以及存档保留期说明和“默认保留”标签。
- Windows NSIS 安装版不显示空说明占位；portable 下载提示继续保留。
- 自动更新开关“已开启 / 已关闭”固定为 `14px`。
- 自动更新内容与分隔线右边界对齐全局【确认】按钮左缘，在两种窗口和三种缩放下误差不超过 `1 CSS px`。
- 平盘第二项仅将显示文本改为“平盘对账数据处理”，内部值与纯前端占位范围不变。

## 4. 兼容性与失败行为

- 不迁移既有合法存档保留期，不修改历史存档批次。
- 模板排除配置全部作废，不保留隐藏生效行为。
- 存档设置加载或保存失败时不得静默关闭；用户可以看到错误并重试或关闭放弃。
- 不改变自动更新检查、下载、安装、开关持久化和状态机。
- 不实现平盘业务后端，不新增数据库、业务 IPC 或 Excel 契约。
