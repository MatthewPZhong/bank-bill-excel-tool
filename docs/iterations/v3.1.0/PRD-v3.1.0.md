# PRD v3.1.0

## 范围

v3.1.0 将“平盘对账数据处理”从前端占位升级为第一期可用功能，交付平盘资金性质校验、五类链接原始表管理、结果回导确认、差异审计和持久化 side DB。

## 人工门禁

真实或脱敏资金数据必须逐笔复核十组 FundType、账户别名、币种、方向、日期、手续费、严格 1:1、结果回导和最终存档；自动测试不能替代人工签字。
