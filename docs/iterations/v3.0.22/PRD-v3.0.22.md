## 0. 迭代目标

在现有设置页增加“存档中心”，保存 11 个主模块在当前启动周期内可证明来源的业务输入文件及对应批次第一次成功结果。

存档用于查找、只读打开和复制文件，不提供恢复业务、重新运行、编辑、替换原文件或历史数据补录。

## 1. 页面与用户行为

- 设置页左侧导航固定为“自动更新 / 存档中心”，每次打开默认进入自动更新。
- 支持按本地日期、主模块和批次号查看批次及文件详情。
- 文件显示输入/输出方向、角色、原文件名、大小和存档状态。
- 批次支持锁定、解锁、永久删除和失败重试；文件支持只读打开和另存为。
- 默认保留 90 天，可选 30/90/180/365 天或永久；锁定批次不参与自动清理。
- 网银账单模板可配置“不存档”，命中任一排除模板时整个批次跳过。

## 2. 批次与业务边界

- 有运行按钮的模块仅在运行成功后建批；只导入、运行失败或取消不建批。
- 无运行按钮的模块在成功生成内部结果时建批。
- 每批只保存本次启动周期可证明的输入和第一次成功结果；后续另存、重复导出、聚合、区间和历史重导不追加。
- 链接表和临时 MPT 成功导入使用独立输入批次，不重复挂到每次正式运行。
- 显式 run key 只允许精确绑定；找不到时不得回退到最新批次。
- 临时 MPT、正式前置资金对账、资金对账和对账单修复使用隔离活动域。

## 3. 存储与生命周期

- 主库四张轻量表保存批次、不可回退日流水、逻辑文件和 Blob 元数据；不保存 Excel 字节或业务数据行。
- 文件存入 Documents 下固定存档目录，以 SHA-256 内容寻址；相同内容全局物理去重。
- 同批全部文件先登记再复制；业务成功时记录文件身份，后台复制前和复制后复核，文件变化时拒绝错存。
- 删除批次先移除逻辑引用，只有最后引用删除时才释放物理 Blob。
- 启动时修复中断状态、断裂引用、孤儿 Blob、staging 和只读临时副本。
- 正常退出和在线升级重启等待存档队列完整排空；5 秒仅记录慢退出告警。

## 4. 安全与失败隔离

- Renderer 仅按批次 ID 和文件引用 ID 操作，不取得源路径或 Blob 内部路径。
- 打开文件先生成独立只读副本；另存为不得写回存档根，也不能通过目录链接绕过限制。
- 存档目录不可写、源文件丢失、磁盘或元数据错误不得改变原业务成功状态和正常结果文件。
- 一般失败可重试；业务成功后源文件已变化时要求重新执行原业务，不能重试变化后的字节。
- 活动日志和通知只报告存档失败，不记录源文件绝对路径或表格内容。
