# [v3.0.26] 前置资金导出与 R5 手续费迭代

## 一、交付内容

1. 平盘模块“对账表管理”改为“对账数据管理”；资金链接表删除框标题固定为“删除数据”，实际删除目标与成功提示仍按所选表执行。
2. 前置资金对账“不平结果”在第 6 列增加银行原始 `FundType`，模板由 20 列升级为 21 列。
3. C4 严格兼容旧 19 列“对账结果”、旧 20 列“不平结果”和新 21 列“不平结果”，继续投影为既有 19 列内部数据。
4. R5 两种来源和调拨多对多审计统一使用 `abs(Credit-Debit) + signed Extra Fee`；非法手续费退出候选并进入主错误报告。
5. DBS-Charge 两个步骤显式保留不含 `Extra Fee` 的旧金额口径。
