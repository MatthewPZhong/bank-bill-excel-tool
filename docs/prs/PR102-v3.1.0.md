# [v3.1.0] 平盘资金性质校验

PR：https://github.com/MatthewPZhong/bank-bill-excel-tool/pull/102 ｜ 分支 `codex/v3.1.0-position-reconciliation` → `main`。

## 一、交付内容

1. 将「平盘对账数据处理」从占位模块升级为第一期可用的「平盘资金性质校验」。
2. 增加平盘银行对账单、五类链接原始表/对账表、独立账户映射、数据管理和差异管理。
3. 十组 FundType 使用可审计规则判断，订单类执行单次及跨已确认运行的双向严格 1:1。
4. 增加固定 49 列结果、实际修改标黄、回导防篡改、最终确认和状态更新。
5. 批量明细只进入独立持久 side DB；输入使用不可变暂存副本，并接入存档中心。
6. 存档失败暂存副本可跨重启重试；跨批次共用源路径在最后一个未完成 artifact 解决前不会释放；存档写操作纳入统一退出闸门，银行导入错误展示文件级明细。
7. 草稿绑定数据 revision 和规则版本，数据、映射或规则变化后禁止继续导出、回导或确认。
8. 主库与 side DB 使用实例身份、generation 和事务 token 建立 checkpoint 门禁，缺失、空库、合法旧库回滚和同代分叉均阻断；运行 JSON 与明细交叉校验。
9. 静态模板与运行时 writer 复用标识符文本列判定，空表仍保留 ID、账号、卡号、ReconID、CustomerRef 和客户编号格式。
