## 一、主体改动

### 1. 前端 UI
- 「银行对账单处理」模块面板沿中线镜像对调（复用 `.layout-mirrored` / `direction:rtl`）；不影响 `recon-id-fix` 模块。
- 「对账单 ReconID 修复」场景管理去掉「银行渠道」维度（compact view 隐藏渠道下拉 + 管理按钮）。

### 2. 文本变更（仅显示文本，DB category 值不变）
- 模块名「月度 Pending 数据核对」→「月度Pending数据核对」（去空格，含 usage-stats key 同步）。
- 功能类别：「提取ReconId-From 网关」→「网关对账单赋值银行对账单」；「银行对账单字段赋值」→「银行对账单赋值自身」。
- 内置场景名「从银行对账单的信息里提取对账ID」→「…提取调拨订单对账ID」（含老库幂等迁移 `ensureBuiltinFixedScenarioNameUpdate`）。

### 3. 新增功能：复制场景
- C1~C4 配置弹窗右上角「复制场景 / 选择」；用所选源场景 `config` 覆盖当前编辑场景配置，**不覆盖名称**；新建/修改均可用。
- 银行对账单处理按「渠道 + 场景」两级下拉，ReconID 修复按「场景」单选。

### 4. 自带写死场景（builtin-fixed）
- 新增 DB category `builtin-fixed`：前端无新建入口、仅「通用」渠道可见、序号固定置顶、优先级 0、仅「管理」按钮、保留启用勾选。
- 新增**场景-渠道多对多关联表** `scenario_applicable_channels`（适用银行渠道多选，默认全选=全部渠道生效）。
- 执行引擎 `runScenario` 加 builtin-fixed 路由，实际仍跑 `extractByFeature` 提取逻辑（功能不变）。

### 5. Win 端字体策略
- 仅 win32 + 默认 Clear 主题：英文/数字 Courier New、中文 Noto Sans SC（`src/fonts.css` 本地子集打包）；大标题保留原字体，macOS 不受影响。
