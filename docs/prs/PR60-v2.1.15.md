### 各项要点

**W0**（`acquiring-bill-currency-writer.js` + `run-repository.js`）：`writeDiffWorkbook` 内层 `LIMIT/OFFSET` 深分页 → 单次 `stmt.iterate` 游标遍历（新增 `iterateDiffRowsByDateRange`，SQL body 与 `listDiffRowsByDateRange` 逐字相同，仅去 LIMIT/OFFSET）。消除整月差异行落在单一 segment 时 OFFSET 深分页 + 无索引 `json_extract` 排序导致的 O(N²) 退化。**50 万差异行 ~61.6s→5.2s（≈11.9x）**，新旧 xlsx 逐 sheet 逐行逐列对拍一致。

**W1**（新增 `gateway-recon-headers-loader.js` + `main.js` + `preload.js` + `renderer-dialogs.js`）：C3「网关账单字段」枚举从硬编码 `GATEWAY_RECON_FIELDS`（31 列）改为运行时读 `assets/网关对账单.xlsx` 第一个 sheet 表头（复用 C2 FundType「main 读 + IPC + renderer 异步缓存」模式）；缺失/失败/空表头降级回旧硬编码；剔除 `__CUSTOM__`。⚠️ **破坏性**：新表头与旧硬编码 31 列几乎全不一致，**存量 C3 场景引用旧字段名的配置失效，需重配**。

**W2**（`c3-gateway-recon-join.js`）：重构 `runC3Scenario` 赋值段——assign 与 Extra Fee 两段写盘解耦（各自 `old≠new` 才 record/标黄，最后统一 `lock` + 单向消费网关行）；勾选「金额不一致」匹配成功后差额写银行行 `Extra Fee` 标黄；原值=差额则只锁定不标黄；1v1 红线不变。

**W3**（`renderer-dialogs.js`）：`createScenariosManagerDialog` header 加「网关对账单修复 [管理]」，复用 `['gateway-recon-id-fix']` 打开 ReconID 网关场景管理；仅资金对账入口显示。

**W4**（`index.html` / `renderer.js` / `preload.js` / `main.js` / `settings-repository.js` / `database.js`）：删调色盘「切换页面风格」+ General 链路；老库 `ui_style='General'` 启动迁移 Clear；`styles.css` 保留不删。
