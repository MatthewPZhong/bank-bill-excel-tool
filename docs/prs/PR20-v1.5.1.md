# PR #20 — v1.5.1：补齐 1.5.0 + 1.5.1 文档三件套

## 背景

v1.5.0（PR #17）、v1.5.0-fix2（PR #18）、v1.5.1（PR #19）合入 main 时，文档三件套（CHANGELOG / VERSION_FEATURE_HISTORY / USER_GUIDE）没有同步更新，CHANGELOG 最新版本停留在 1.4.9。

按 README / CLAUDE.md 约定，每次版本迭代都应同时更新这三个文件。本 PR 一次性补齐 1.5.0 和 1.5.1 两节。

## 改动文件

- `CHANGELOG.md`（+29 行）— 新增 `## 1.5.1 - 2026-04-13` 和 `## 1.5.0 - 2026-04-12` 两节
- `docs/VERSION_FEATURE_HISTORY.md`（+54 行）— 新增 1.5.1 + 1.5.0 两节，按「新增 / 变更 / 移除」分组整理
- `docs/USER_GUIDE.md`（+52 / -2 行）
  - 顶部版本号 `v1.4.9` → `v1.5.1`
  - 1.1.2 主要功能追加 3 条（主/子模板 / 账户映射按模板隔离 / 文件重复判定）
  - 1.1.4 相关功能 Q&A 新增 5 条（12 指定账单 / 13 使用手册导出 / 14 主/子模板 / 15 账户映射按模板隔离 / 16 文件重复判定）

## 改动内容

### 1.5.1 三件套补齐

**CHANGELOG.md**：详细记录 v1.5.1 全部改动，覆盖主/子模板（DB 迁移 `parent_template_id` + `is_parent`）、账户映射按模板隔离（`account_mappings` 表重建）、Bundle v4、重复判定增强（SHA-256 三维度判重）。

**USER_GUIDE.md**：主要功能列表增加 3 条 v1.5.1 能力；Q&A 补充三个常见问题的使用指引（14 主/子模板如何配置和互斥关系；15 账户映射按模板隔离和迁移分配对话框；16 文件重复判定的三维度规则和对话框选项）。

### 1.5.0 三件套补齐

**CHANGELOG.md**：详细记录 v1.5.0（PR #17）+ v1.5.0-fix2（PR #18）全部改动。覆盖发生额精度 12 位、大账号确认页重构、提取大账号顺序功能、「记住顺序」持久化增强、模块名称变更、英文日期格式解析、模板包同名覆盖确认、使用手册 txt/md/html 导出、单滚动条重构、指定账单实现功能、映射字段列位置固定、映射互斥补全等。

**VERSION_FEATURE_HISTORY.md**：按「新增 / 变更 / 移除」分组整理 v1.5.0 功能点。
