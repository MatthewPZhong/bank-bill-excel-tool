# PR — [v2.1.0-beta.2] ReconID UI 精修 + 场景管理跨模块隔离 + 窗口控制按钮 hit-test 修复

## 范围

v2.1.0-beta.1 用户实测后的 UI 精修迭代。3 个核心方向：
1. **场景管理跨模块隔离**（v2.1.0-beta.1 遗留 bug：两个入口看到同一锅 4 类场景）
2. **全局窗口最小化 / 最大化 / 关闭按钮无响应**（hit-test 被拖拽区域罩住）
3. **ReconID 模块 UI 大规模精修**（主面板布局、C4 dialog 各项细节、场景管理列表 dialog 增强）

共 **39 项改动** 通过 4 轮用户测试迭代（PR-A → PR-B → Round 2 → Round 3 v2）后稳定，按用户指示**合并为单一 PR 提交**（PR-A/PR-B/Round 2/Round 3 改动同一 commit）。

涉及文件 **5 个 src 文件 + 4 个迭代文档 + 3 个发布文档 + 9 个 preview PNG**。

## 改动清单（4 轮迭代）

### PR-A 业务隔离 + 窗口 bug（5 task）

- **A1** `createScenariosManagerDialog(allowedCategories)` 接收白名单 + 内部过滤 list + 设置 `state.activeScenarioListFilter`
- **A2** `createScenarioCategorySelectDialog(allowedCategories)` 按白名单过滤可见类别；单类别入口跳过类别选择窗
- **A3** renderer.js 两入口传白名单
- **A4** styles-gemini.css 加 `.no-drag` rule 修复窗口按钮 hit-test
- **A5** preview 重跑 + 新增 ReconID 场景管理 preview 状态

### PR-B 6 项 UI 调整（7 task）

- **B1** ReconID 主面板布局对齐银行对账单（行 1 左 cell = [场景下拉 + 场景管理]）
- **B2** C4 dialog 单据匹配规则 3 勾选框单行排列
- **B3** C4 dialog commonId 下拉移除 narrow class（先 max-content 自适应，Round 2 R2-5 改 130px，Round 3 R3 调 155px）
- **B4** "+ 新增 OR 分组" → "+ 新增对账分组"；分组间 OR 文字去除留间距
- **B5** dialog 标题精简（仅 C4 省略 ` — 单据对账修复`，C1/C2/C3 保留）
- **B6** 4 dialog actions 顺序 [取消 确认] → [确认 取消] + 右下对齐
- **B7** preview 重跑

### Round 2 13 项 UI 优化

- **R2-1** 删除按钮 × 居中（`inline-flex + line-height: 1`）
- **R2-2** SubBizType "（三选一）" 后缀去除
- **R2-3** 场景名称 label 中线对齐 input（移除全局 padding-top，仅多行 row 保留）
- **R2-4** 分组序号 "分组 N" 与"左："等同行显示（`flex: 0 0 auto; white-space: nowrap`）
- **R2-5** commonId 下拉宽度 155px（用户复测从 130 调到 155；`flex: 0 0 155px` 覆盖默认 `flex: 1` 才生效）
- **R2-6** 场景管理 dialog 右下"完成"按钮（关闭 + 刷新主面板下拉）
- **R2-7** 场景管理 dialog 序号 1-based 顺序（不再用真实 scenarios.id；dataset.id 保留真实 id）
- **R2-8** 单类别入口 compact 模式：filter.length === 1 时隐藏 优先级 + 是否启动 列
- **R2-10** "+ 新增字段对" → "新增"
- **R2-11** "新增"按钮仅每组第一行渲染（账单类型 + 对账字段）
- **R2-12** 账单类型 + 对账字段所有下拉框左右边界垂直对齐（grid 列定义共享 + HTML 合并 label + 加 spacer + white-space: nowrap）
- **R2-13** Amount 锁定行视觉对齐（`box-shadow inset` 替代 `padding: 4px 6px + border-left: 3px`，不占布局空间；**不解锁业务**——引擎仍依赖 Amount/Amount 锁定）

### Round 3 v2 8 项 UI 优化（第 1 轮 R3 整批回滚后重做）

- **R3-1** "=" 在 fieldpair grid col 3 内水平居中（`text-align: center`）
- **R3-2** 场景名称 input 宽度 180px（4 dialog 共用 `input[data-field="name"]`）
- **R3-3** ReconID 状态框宽度 292px (= pending-action-pair 宽度)，与 [导入文件] 左对齐 + [开始运行] 右对齐
- **R3-4** 导出文件按钮平移至场景管理下方（cell.left flex-end + 按钮 min-width 140px 统一）
- **R3-5** 场景下拉宽度 min-width 160→120, max-width 220→165（3/4）
- **R3-6** 整体右移 + 缩距：保留 grid 1fr:1.4fr 让 [场景下拉] 不动；transform translateX：[场景管理]/[导出文件] 100px、[pending-action-pair]/[statusBox] 74px → 距离 ≈ 80px（用户复测从 47 调到 74）
- **R3-7** 状态框初始文本统一 "欢迎使用小助手"（index.html L242 + renderer.js L3512 默认分支）
- **R3-8** 行 2 label "单据匹配规则" → "匹配规则"
