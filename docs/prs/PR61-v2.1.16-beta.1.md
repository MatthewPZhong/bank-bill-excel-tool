# [v2.1.16-beta.1] 阶段一·地基层

## 概述

v2.1.16 迭代**阶段一·地基层**（版本 `2.1.16-beta.1`）。为「资金对账数据处理」模块补齐批量导入、链接表持久化、自带场景优先级等地基能力。**纯新增 + bug 修复，不破坏现有功能**，main 仍可发布。

> 阶段二（资金性质校验 + 5 轮对账编排 + 网关对账单 reader + 期权表）待续，将从 main 切新分支续 `beta.2` → 转正 `2.1.16`。

## 改动清单

### 1. 批量导入（按表头自动识别）
- 「导入对账单」改为**批量入口**：多选文件 + 按表头自动识别表类型（新增 `table-type-detector.js`，L1 精确 + L2 模糊两层）
- 多份银行对账单**合并对账**（追加不覆盖）：抽 `bank-statement-merge.js` helper —— 🔴 合并后 `_rowId` 全局重编号保证跨文件唯一，dispatcher `rowLockSet` 锁定不变量保持（已验证 9888 行无漏对/误锁）
- 中台退款/入账原始表识别到 → 本阶段功能开关默认关，标「未启用跳过」

### 2. 链接表管理持久化
- 导入持久化：网关对账单 / 中台调拨订单 / 外汇交割 3 表库，**混合存储**（提取 join 键列 + 日期列建索引 + `raw_json` 整行，对齐 acquiring 50 万行生产模式）
- 弹窗渲染真实「数据日期范围 / 表库更新日期」
- 外汇期权表占位（模板已入库，待阶段二接入）

### 3. 自带场景优先级
- 自带写死场景「管理」弹窗新增「优先级」输入框（与「银行渠道」并列居中）

### 4. 修复 / 规范
- 链接表中台调拨订单数据日期范围改用「交易时间」（修正「业务日期」空值率高导致的漏行）
- 链接表 `linked_mid_allocation` 列名 `business_date` → `transaction_date`（语义对齐，新表零存量）
- assets 模板库规范：新增 `外汇期权订单.xlsx` / `外汇交割表.xls`（rename 自 vPayment），更新 `中台加款单剔除模板.xlsx`
