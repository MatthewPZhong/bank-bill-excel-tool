## 关键决策

- **算法引擎独立 module**：`src/main-process/scenario-engines/` 5 个文件，纯函数；不放 main.js（避免 7500 行膨胀），不放 dialog（属 main 进程业务逻辑）
- **算法稳定签名**：`runScenario(scenario, bankRows, gwRows?) → { lockedRowIds: Set, modifications: [], warnings: [] }` —— PR #32 调度直接消费
  - `lockedRowIds`：first-match-wins 锁定 + 仅导修改行（C2 配对成功时双方都锁，即使 leftRow 未改字段）
  - `modifications`：标黄依据
  - `warnings`：error-report 依据
- **字段枚举常量化**：44 列 + 31 列写在 `src/constants/`，runtime 不从导入文件提取（PRD D7 列结构固定）
- **C2 笛卡尔配对**：账单类型分组 + 一对一标 + 一对多 / 多对一 warn + 双方都锁（PRD §7.2 + Codex F2 修复）
- **C3 4 字段 AND join**：多行匹配取首 + warn；网关字段 'Currency' 大小写敏感（与 sheet 实际表头对齐，Codex F3 修复）
- **发生额绝对值虚拟字段**：`'发生额绝对值'` = `Math.abs(Credit Amount - Debit Amount)`，仅 C3 银行字段下拉用
