# [v3.1.4] 平盘来源异常行审计过滤与导出

PR：https://github.com/MatthewPZhong/bank-bill-excel-tool/pull/114 ｜ 分支
`codex/v3.1.4-position-filtered-source-import` → `main`。

## 一、交付内容

1. 调拨单和测试付款单新增白名单行分类：允许明确无效的证据缺失行自动过滤，
   正常行继续落库；付款成功调拨缺证据和其它硬错误继续整文件拒绝。
2. preflight/apply 双阶段复算 sealed ledger，保护物理行去向、重复 owner、业务键碰撞、
   报告依赖和逐文件事务原子性。
3. 过滤行不写来源表、不生成链接腿，改为保存活动墓碑并绑定来源 revision、不可变报告
   SHA-256/size 和存档引用。
4. 导入完成后可立即导出异常报告，存档中心保留同一字节文件；运行冻结过滤墓碑，
   结果确认页常驻“过滤数据导出”。
5. 报告损坏、依赖不闭合、来源 revision 漂移、业务键碰撞或整月必要来源全量过滤时
   失败关闭，不静默产生不完整资金结果。
