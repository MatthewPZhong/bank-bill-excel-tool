# [v3.0.25] 设置弹窗、存档策略与平盘文案调整

PR：https://github.com/MatthewPZhong/bank-bill-excel-tool/pull/100 ｜ 分支 `codex/v3.0.25-settings-dialog` → `main`。

## 一、交付内容

1. 设置弹窗底部统一为【确认】；进入存档设置后由全局【确认】保存保留期限并关闭，保存失败时保留弹窗与错误反馈。
2. 修复永久保留回显与存档设置异步加载竞态；返回、切页或关闭会失效旧请求，加载完成前禁止确认。
3. 彻底退役网银模板“不存档”：删除 Renderer、Preload、Main IPC 和 Controller 接口，升级启动后将旧排除配置统一归一化为 `[]`。
4. 存档默认保留期改为 60 天，下拉支持 30、60、90、180、365 天和永久；既有合法设置不迁移。
5. 删除指定自动更新与存档说明，统一开关状态字号为 `14px`，并将自动更新内容右边界对齐全局【确认】按钮左缘。
6. 平盘功能第二项显示名称改为“平盘对账数据处理”，内部值 `position-data-info-backfill` 保持不变。
