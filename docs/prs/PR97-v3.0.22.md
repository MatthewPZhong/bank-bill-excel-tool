# [v3.0.22] 设置页内存档中心

PR：https://github.com/MatthewPZhong/bank-bill-excel-tool/pull/97 ｜ 分支 `codex/v3.0.22-archive-center` -> `main`。

## 一、交付内容

1. 设置页增加“自动更新 / 存档中心”双导航，默认仍进入自动更新；存档中心不新增主模块。
2. 对 11 个主模块保存当前启动周期内可证明来源的业务输入和第一次成功结果。
3. 使用 SQLite 轻量索引与 SHA-256 内容寻址 Blob，支持全局去重、保留期、锁定、删除、失败重试、只读打开和另存为。
4. 链接表与临时 MPT 使用独立输入批次；运行批次按模块、批次类型和 run key 隔离。
5. 存档失败不改变原业务返回；正常退出和在线升级重启会等待存档队列完整排空。

## 二、Self-review 修复

- 显式历史 run key 未命中时不再回退到最新批次。
- 临时 MPT 修复按源文件与结果下标绑定，避免同名文件串绑。
- 业务成功后立即固化文件身份，排队期间文件变化时拒绝把新内容冒充原输入或结果。
- 月度余额不再覆盖普通网银账单的活动批次。
- 同批文件在首个复制动作前全部登记，正常退出不丢弃尚未开始的存档任务。
- 另存目标同时检查词法路径和真实目录，阻止目录链接绕过存档根保护。
