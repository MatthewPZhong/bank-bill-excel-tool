## 二、🔴 对外契约变更（合并适配提示 · 升级必读）

1. **银行对账单模板 44 → 46 列**（迭代2 · 🔴 资金红线）：新增「合并单号」「合并状态」。软件识别 + 字段下拉可选 + BU 回填兼容导入忽略两列、不落库；新旧 44/46 列文件均可识别（指纹列不变）；旧版 44 列文件行为完全不变、Pending 严格校验零波及；合并单号 / 合并状态不写入 `bank_bu_recon_bank_imports`。下游依赖固定 44 列的脚本遇 46 列新文件需忽略多出两列。
2. **`streaming-xlsx-reader.js` 读值正则修复（含首尾空格字符串不再被读空）**（BUG3 顺带 · 🔴 资金红线 · 影响银行对账单导入读值 · 升级必读）：`V_CONTENT_RE` 由 `/<v>...<\/v>/` 改为 `/<v(?:\s[^>]*)?>([\s\S]*?)<\/v>/`，修复「`<v>` 带 `xml:space="preserve"` 的含首尾空格字符串单元格被旧裸标签正则漏匹配 → 读空」的隐性丢值 bug（裸 `<v>` 仍匹配，向后兼容）。⚠️ **该读取器被银行对账单导入复用** → 升级后此前读空的含首尾空格列会读到真实值，对账 / 校验输入可能随之变化（绝大多数无空格列不受影响）。**强烈建议用真实银行对账单数据回归一遍导入读值**。
3. **工具箱合并 / 拆分大文件改流式（30 万行不再闪退）**（BUG3 · 🟡 性能）：SheetJS 全量读 → 流式读 + `WorkbookWriter` 流式写，根治大文件 OOM 闪退、大文件不再被误吞成「文件为空」（改「文件过大」真实文案）。**输出与现状 `writeWorkbookRows` 完全一致**，合并合计超 Excel 单页数据行硬上限（1,048,575）自动开 sub-sheet (2)(3)，`.csv`/`.xls` 回退全量读。无对外列契约 / 文件名规则变化。

## 四、合并前 codex + self-review 追加修复（F1）

PR 提交后做了一轮 codex review（`codex exec review --base main`）+ self-review，发现并修复 **F1（🟠 Important · 工具箱多 sheet 乱序读错 sheet · BUG3 流式化引入的回归）**：

- **现象**：codex 实测复现——构造 2-sheet 文件并交换 `workbook.xml` 里 `<sheet>` 元素顺序（改 tab 顺序、不改物理 part 名）后，全量 `readRows` 读 `SheetNames[0]`（显示首 tab=B）、流式 `readXlsxStreamed` 硬编码读物理 `sheet1.xml`（=A），两者读**不同 sheet**。
- **根因**：`toolbox-stream-io.js` `isStreamableXlsx` 对任意 .xlsx 返回 true、缺「物理单 sheet」护栏；而旧工具箱走 `readRows`（读 `SheetNames[0]`）→ 工具箱合并/拆分对乱序多 sheet 文件静默读错 sheet（相对 BUG3 之前的行为回归）。
- **范围澄清**：🔴 银行对账单导入（资金红线）**不受影响**——该路径早有单 sheet 护栏（detector `readXlsxSheetMetaLite` + `detectTableType` 只对物理单 sheet 走流式）。F1 只波及工具箱。
- **修复**（仅 `src/main-process/toolbox-stream-io.js`，**main.js 零改动**）：新增 `isPhysicallySingleSheetXlsx`（`readXlsxSheetMetaLite().worksheetEntryCount===1`，解析失败 catch→false 安全回退）+ `canStreamXlsx`（=.xlsx 且物理单 sheet）；`streamDataRows` / `readHeaderRowStreamed` 内部闸门由 `isStreamableXlsx` 改为 `await canStreamXlsx` → 多 sheet .xlsx 自动落入既有 `else { readRows }` 读 `SheetNames[0]`（正确、与旧工具箱一致），物理单 sheet 仍流式（BUG3 的 OOM 修复保住）。与 detector 既有护栏同款。
- **验证**：新增 `tests/unit/main-process/toolbox-stream-io.test.js`「F1 乱序多 sheet 护栏」组（fork-fixture 自证分叉 + canStreamXlsx 多/单/csv 三态 + 读对 sheet 断言 + 单 sheet 不退化）；独立对抗验证 agent 用 call-spy 实证多 sheet 期间 `readXlsxStreamed` 调 0 次（真走 readRows）、单 sheet 调 2 次（仍流式）+ 反事实证伪 bug 真实存在；team-lead 自审 diff + 复跑 release-check exit 0。
- **改动文件**：`src/main-process/toolbox-stream-io.js`（+33/-3）/ `tests/unit/main-process/toolbox-stream-io.test.js`（+102）。
