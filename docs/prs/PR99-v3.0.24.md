# [v3.0.24] 平盘对账前端与 Payment 多大账号支持

PR：https://github.com/MatthewPZhong/bank-bill-excel-tool/pull/99 ｜ 分支 `codex/v3.0.24-position-reconciliation` → `main`。

## 一、交付内容

1. 新增默认位于闲置功能的「平盘对账数据处理」主模块；本版只交付三项功能枚举、五个占位按钮和状态框，不接业务 IPC、数据库或 Excel。
2. 页面沿用对账单修复的两行结构；仅「开始运行」为蓝色主按钮，其他按钮为白色次按钮，「开始运行」与「导出文件」宽度固定为 `140px`。
3. Payment 线下调拨订单回填的 `bigAccount` 扩展为严格中文顿号分隔列表，继续使用原字符串 schema，不新增迁移。
4. R1/R2 按账号与周分桶，R3 兜底同样要求银行大账号与订单收款账号相同；三轮继续共享全局 1:1 消费集合，禁止跨账号回填。
5. 非法历史配置安全 no-op，并通过 `payment-offline-invalid-big-account-config` 进入可见错误报告。
