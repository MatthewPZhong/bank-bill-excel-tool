## 一、交付内容

1. 银行和五类链接原始表迁移到 utility process 流式解析与增量写库，主进程不再持有
   随输入行数增长的完整 workbook、行、主键、冲突和派生集合。
2. 银行整批原子、普通来源逐文件事务、账户确认替换三类边界保持不变；业务数据、
   revision、input proof、checkpoint 和存档证据使用同一提交事实。
3. 普通来源使用完整规范行 `row_hash/sourceRecordKey` 作为技术身份；完全重复折叠，
   同业务主键不同内容全部保留并独立派生与消费。
4. 银行摘要、来源摘要、删除和 FundTransfer 映射重建改为索引聚合或后台分批作业，
   300 万行管理路径保持有界内存。
5. 导入进度、协作取消、磁盘门禁、worker 崩溃恢复和暂存保护链路完整接入；任何证据
   不一致均失败关闭，不回退主进程旧 reader。
