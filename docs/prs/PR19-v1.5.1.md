## 改动内容

### 需求 1：主/子模板

- **DB 迁移**：`templates` 表新增 `parent_template_id`（nullable FK, ON DELETE SET NULL）+ `is_parent`（INTEGER DEFAULT 0）
- **映射关系管理页面**：dialog header 新增「设为主模板」「设为子模板」checkbox，互斥逻辑，子模板时出现主模板下拉框
- **模板管理页面**：新增「模板管理」标题；主模板行有 ▶/▼ 展开折叠按钮，子模板缩进显示
- **主页面下拉框**：`.filter(!parentTemplateId)` 过滤子模板
- **文件导入自动匹配**：`matchFileToTemplate` 按 headers 精确匹配候选模板；`parentProvisionalEntries` 暂存匹配结果；`rebuildMatchedTemplateFileEntries` 在大账号选定后重建 rows
- **Checkbox 状态回显**：重新进入映射管理页时根据 DB 的 isParent/parentTemplateId 正确回显

### 需求 2：账户映射按模板隔离

- **DB 迁移**：`account_mappings` 表重建——新增 `template_id`（NOT NULL FK）、改 UNIQUE 为 `(template_id, bank_account_id)` 联合唯一。事务保护（BEGIN/ROLLBACK）。多模板时旧记录复制给每个模板，设 `account_mapping_migration_pending` flag
- **迁移分配对话框**：首次打开账户映射检测 flag → 弹分配 UI 引导用户分配旧数据
- **模板下拉框**：传 `state.templates` 全量列表（含子模板），可选子模板配置映射
- **表头文案**：「网银大账号ID」→「网银账单账户号」、「清结算系统大账号ID」→「清结算系统银行账号」
- **执行操作列**：编辑/完成切换交互；编辑/完成按钮左对齐（`text-align: left`）
- **币种 tooltip**：ⓘ 图标 hover 显示说明文本，`z-index: 9999` 防遮挡
- **noCurrency 自动检测**：移除 checkbox，`getNoCurrency: () => currencyInput.value.trim() !== ''`
- **多币种桥接提醒**：提取大账号顺序时检测桥接匹配 + 多币种 → 弹提醒框
- **账户映射缺失不阻断**：移除截断检查

### 需求 3：模板管理页面标题

`createTemplateManagerDialog` dialog-header 新增 `<div class="dialog-title">模板管理</div>`。

### 需求 4：Bundle v4

- `SUPPORTED_BUNDLE_VERSION = 4`
- 导出：`buildTemplateLibraryPayload` 追加 `parentTemplateKey` + `accountMappings`
- 导入：三阶段还原（模板 → 父子关系 → 账户映射）
- v3 向下兼容（缺失字段默认空值）

### 需求 5：重复判定增强

- `computeFileHash` SHA-256 哈希
- `resolveImportFileSelection` 三维度判重：路径 > 文件名 > 内容
- 对话框改为两按钮（覆盖旧记录 / 取消本次导入），移除「保留两份」
- 提示框显示重复原因
