# [v3.0.19] 工具箱支持多 Sheet 合并

PR：https://github.com/MatthewPZhong/bank-bill-excel-tool/pull/94 ｜ 分支 `codex/v3.0.19-toolbox-multi-sheet-merge` → `main`。

## 一、交付内容

1. 工具箱「合并表格」支持单个文件多个 Sheet，以及多个文件多个 Sheet 合并为一份工作簿。
2. 支持 `.xlsx`、`.xls`、`.csv` 混选；Excel 读取全部可见非空 Sheet，CSV 作为单张表。
3. 按文件选择顺序、Sheet 标签顺序和原始行顺序输出；每张 Sheet 独立识别并严格校验表头。
4. 隐藏、深度隐藏和空白 Sheet 跳过；只有表头的 Sheet 参与校验但不贡献数据行。
5. 输出默认使用 `COMMON`；超过 Excel 单页上限时自动续写 `COMMON(2)`、`COMMON(3)`。
6. 读取、校验、写出或发布失败时清理临时产物，并恢复可能被覆盖的旧目标文件。
7. 单 Sheet 合并、IPC 返回契约、默认文件名和多 Sheet 拆分语义保持兼容。
