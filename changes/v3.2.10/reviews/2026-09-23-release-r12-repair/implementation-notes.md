# RR12-01 修复记录

## 决策与范围
- 目标：普通单调用数组 helper 不再使 Renderer 静态身份分析栈溢出；保留违规拒绝和安全对照。
- 复用 release/v3.2.10 工作区及既有未提交修复。冻结起点 HEAD 9a38b96b、4966 个文件；仅修改 Renderer 检查器、增加本轮回归及必要说明。
- 数组分配身份与数组元素解释分开：身份解析保留原调用环境，延后展开内容；确实读取元素时沿原 depth/visited 继续求值。避免为比较 helper 接收者而反复展开同一数组。
- helper 的唯一调用入口复用于参数绑定与执行时点比较。数组来源在外层时也能恢复 helper 的调用位置，区分先写后重排和先重排后写。
- 不修改共享 scan/contracts/rules、边界或例外配置，不精确模拟 reverse 等数组方法，不新增覆盖豁免。
