# Test Spec — v3.0.17 退款模糊匹配与多文件拆分

> status: automated-pass / manual-funds-review-pending
> created: 2026-07-16

## 1. 退款 P0

| 场景 | 预期 |
|---|---|
| 旧配置缺开关 / 明确关闭 | 旧退款结果不变 |
| ChannelOrderNo / CustomerRef | 任一字段精确匹配均可形成候选 |
| 金额差 9.99 / 10 | 前者可命中，后者不命中 |
| 账号或币种不同 | 不形成候选 |
| S1-S4 已有结论 | 新规则不推翻 |
| 普通未命中 | 仅该类可被救回 |
| 银行一对多 / 退款多对一 | 全部转人工，不抢占 |
| 非法金额 | 不降级为零，原因可见 |
| 成功输出 | 命中类型、详情、标黄和人工 sheet 移除正确 |
| 行去向 | 每条退款银行候选最终仅一个去向 |

## 2. 拆分 P0

| 场景 | 预期 |
|---|---|
| 未勾选多文件 | 旧单文件请求、保存框和返回不变 |
| 1-8 组增删 | 状态独立，删除后连续编号 |
| 新增继承字段 | 文件名和值为空，仅字段继承 |
| 不同字段 / 重叠值 | 各文件正确，同一行可重复进入多个文件 |
| 零命中 | 生成合法表头文件，matchedCount=0 |
| 非法、保留、重复文件名 | 阻止导出并定位分组 |
| 输出冲突取消 | 不创建、不覆盖任何文件 |
| 覆盖全部 | 一次确认后全部发布 |
| 生成/发布中途失败 | 删除新文件并恢复所有旧文件 |
| 目标路径是目录 | 发布前拒绝，不移动临时产物或目录 |
| 系统阻止旧文件恢复 | 报告并保留备份路径，上层不清理恢复目录 |
| 普通 XLSX / 大文件 / 多 sheet / CSV / XLS | 每种格式只扫描一次，读取语义不变 |

## 3. 分层

- 单元：精确十进制差、候选图与双向唯一性、配置缺省/合并、文件名规范化、分组路由和批量回滚。
- 集成：退款回填 Excel 回读；工具箱普通流式、大文件 worker、多 sheet、CSV/XLS 一次扫描导出。
- UI：退款专用管理页、多文件 1 组与 8 组预览、浮动值面板、滚动和桌面尺寸对齐。
- 回归：完整 `release-check`、`scan:vars`、`check:vars -- --include-minor` 与 `startup:measure`。
- 人工：真实脱敏退款样本逐笔复核。⚠️ 资金红线。
