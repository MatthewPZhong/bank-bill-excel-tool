# changes 版本索引

2026-09-11 按版本整理。一个版本一个目录，分支目录和文件放入所属版本；跨版本资料按实际起止版本单独存放。

- `3.x.x` 总目录统一命名为 `v3.x.x`。
- beta、预发布和功能分支的完整名称保留在对应 `v主版本.次版本.修订号` 目录内。
- 共用合同包、压缩包及副本整体移动，保留内部结构和全部原始内容。
- 通用模板保留在 `templates/`；`待确认/wal-runtime-ux/` 是原有空目录，未找到可靠的版本归属依据。
- 归档文档、日志与证据文件逐字节保留，所以其中记录的历史路径也保留；查找现位置可用下表或 [新旧路径对应表](organization-map.json)。
- 测试和校验脚本读取当前文件时使用新路径或显式路径映射；历史 Git 取证路径和校验值保持原样。
