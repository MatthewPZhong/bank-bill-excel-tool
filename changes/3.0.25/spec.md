## 0. 任务摘要

- Goal：修复存档设置保存入口，退役模板“不存档”，精简设置弹窗，调整保留期限默认值与平盘功能显示名称。
- Context：存档设置原“保存/取消”按钮位于事件委托容器外导致保存不可用；模板排除同时存在于 UI、IPC、控制器及网银/月度余额存档运行时。
- Constraints：保留存档文件结构、通用 `skipArchive`、自动更新机制和平盘内部枚举值。
- Done when：AC-01～AC-17 通过，版本文档、UI 预览、全量门禁、启动性能及重要变量检查完成。

## 1. 已确认决定

| 项目 | 决定 |
|---|---|
| 存档设置提交 | 全局【确认】保存保留期限并关闭整个设置弹窗 |
| 无修改 | 直接关闭，不发保存请求 |
| 保存失败 | 弹窗保持打开，错误可见，按钮恢复可操作 |
| 放弃修改 | 右上角关闭和返回箭头均不保存 |
| 历史模板排除 | 全部作废；启动时统一写回 `[]` |
| 更新已下载 | 自动更新页按钮显示【稍后】；存档页及存档设置显示【确认】 |
| 存档默认保留期 | 缺失或非法配置按 60 天；新增 60 天选项，既有合法配置保持原值 |
| 平盘枚举 | 仅 label 改名，value 继续为 `position-data-info-backfill` |

## 2. 设置弹窗契约

### 2.1 全局按钮

- 正常底部【完成】改为【确认】。
- 存档设置不再显示独立【保存】和【取消】。
- 全局按钮在存档设置页执行：
  1. 比较当前保留期限与已加载值。
  2. 无修改时直接关闭设置弹窗。
  3. 有修改时禁用按钮并调用 `archiveCenter.setRetentionDays()`。
  4. 成功后提交本地状态并关闭整个设置弹窗。
  5. 失败时保留弹窗，显示“存档设置保存失败”，恢复按钮。
- 保存期间重复点击不得产生并发请求。
- 后端 `retentionDays: null` 必须回显为“永久”，不得被默认值覆盖。
- 保留期限枚举固定为 `30/60/90/180/365/永久`；前端默认选中、Controller 缺失/非法配置回退及 ArchiveService 未传值回退均为 60 天。
- 既有合法的 30/90/180/365/永久设置继续生效，不因默认值变化被覆盖。
- 进入存档设置时，在真实设置加载完成前禁用全局【确认】；返回、切页或关闭应使在途加载失效，旧响应不得覆盖后续页面状态。
- 右上角关闭按钮及存档设置返回箭头继续直接放弃未保存修改。
- 存档文件“另存为”、锁定、删除和重试行为不变。

### 2.2 更新下载状态

- 自动更新页仍按 `canRestart` 显示【稍后】或【确认】。
- 切换到存档中心后，全局按钮始终显示【确认】，不得被后台下载状态覆盖。
- “立即检查 / 立即重启升级”等自动更新操作不变。

## 3. 模板排除退役

- 删除存档设置中的“网银账单生成模板”区域、复选框、说明及 Renderer 状态。
- 删除 Renderer、Preload、Main、控制器中的：
  - `listTemplatePolicies`
  - `setTemplateExcluded`
  - `hasExcludedTemplate`
  - 对应 IPC 与模板排除解析/恢复逻辑
- 控制器启动时将 `archive_center_excluded_template_ids` 无条件规范化为字符串 `[]`；合法旧值、损坏值、空值及缺失值均不得继续生效。
- 网银账单生成和月度余额运行时不再基于模板产生 `skipArchive`。
- 存档 operation tracker 的通用 `runtime.skipArchive` 行为保留，供其它明确场景使用。
- 不新增数据库迁移，不删除 app setting key，不修改历史已存在的存档批次。

## 4. 文案、字体与布局

- 删除以下三段文案：
  - “管理软件版本检查、下载与安装。”
  - “开启后每次启动仅在后台检查一次，不会定时检查。”
  - “按日期、模块和批次号查看已参与处理的输入文件与结果表。”
- 删除存档设置中的“锁定批次不参与自动清理。默认保留期为 90 天。”和字段标签“默认保留”。
- Windows NSIS 安装版的更新说明区域无文案时收起；便携版“前往下载”提示继续显示。
- 自动更新开关“已开启 / 已关闭”字号固定为 `14px`，与同一设置区标签和值一致，切换状态不得改变布局。
- 设置卡片使用共享 CSS 尺寸变量描述：
  - 更新内容区左右 padding
  - footer 右 padding
  - 全局确认按钮固定宽度
- 自动更新内容行、分隔线及便携提示右边界与全局【确认】按钮左边缘垂直对齐，两个目标窗口与 100% / 125% / 150% 缩放误差不超过 `1 CSS px`。

## 5. 平盘功能显示名称

- `position-data-info-backfill` 的显示文本改为“平盘对账数据处理”。
- 默认项继续为 `position-fund-nature-check`。
- 其它两个显示文本、五个占位按钮、占位交互、模块 ID 与后端范围不变。

## 6. 非目标

- 不修改存档文件、批次、Blob 去重、清理或重试机制。
- 不修改自动更新检查、下载、安装、开关持久化或状态机。
- 不实现平盘业务后端，不改平盘内部枚举值。
- 不创建 PR、不合并、不创建 tag、不发布 GitHub Release。
