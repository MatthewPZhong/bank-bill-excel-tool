## 1. 背景

v3.2.16 的「字段筛选特征值」规定一个模板只有一套筛选条件，所有选该映射值的字段共用同一个结果。用户需要在同一模板里按不同条件筛出不同的值（如流水号与订单号分别填到不同字段），并能集中维护这些条件。

## 3. 功能规则

### 3.1 映射行

- 可用范围与 v3.2.16 §3.1 相同。
- 映射字段切换为其他值时，「选择特征值」文本、下拉框与【特征值管理】一起隐藏；切回时恢复该行此前的选择。
- 「选择特征值」下拉框的枚举值随特征值的新增、改名、删除即时刷新；已选的特征值改名后显示新名。

### 3.2 特征值管理弹窗

| 操作 | 规则 |
| --- | --- |
| 打开 | 「特征值」下拉框为空白，下方设置区隐藏 |
| 【新增】 | 下拉框置空白，显示空白设置区（分隔符默认“空格”） |
| 选中已有特征值 | 显示该特征值的设置，可修改；选回空白时隐藏设置区 |
| 【保存】 | 设置区显示时：校验 → 写入模板 → 关闭弹窗；设置区隐藏时直接关闭 |
| 【取消】/× | 关闭，不保存当前编辑；已确认的删除不撤回 |
| 【删除】 | 未选特征值：提示“请选择要删除的特征值”。被使用：提示“特征值「X」正被 A、B 使用，请先改选其他特征值后再删除”，不删除。否则弹框“确定删除特征值「X」？”，确认后写入模板，弹窗保留、下拉框回到空白 |

- “被使用”包括主映射弹窗当前（未保存）的选择、拆分/合并映射弹窗当前的选择，以及已保存的主映射与拆分映射。
- 特征值名：必填，去首尾空白，最多 30 个字，同一模板内不能重复。
- 其他设置项的校验、「输入特征值」的自动推导与 v3.2.16 §3.2 相同；「输入特征值」提示语改为“输入后自动填写下面的条件”。

### 3.3 保存映射

- 实际生效的映射（口径同 v3.2.16 §3.4）中有字段选了「字段筛选特征值」但未选特征值时，点【完成】提示“X、Y 选择了「字段筛选特征值」，请选择特征值”，不保存。
- 选择的特征值已不存在时（如另一处已删除），保存与生成都拒绝，提示重新选择。
- 拆分/合并映射弹窗同上。

### 3.4 运行口径

- 匹配口径与 v3.2.16 §3.2–§3.3 相同（拆段、取第一个命中、条件组合）。
- 每个源行对每个用到的特征值只筛一次；选同一特征值的字段填同一个值。
- 筛不出时字段留空。导入提示仍为“N行未筛出特征值，相关字段已留空”（按行计）；报错文件逐项列出 `第N行，特征值“名”，源字段“X”，原值“Y”`。
- BillDate 选该值时，所选特征值的筛选源单元格整格是合计标签且带金额的行，仍按账单自带合计行跳过。

### 3.5 存量与兼容

- 升级后，v3.2.16/3.2.17 已设置的那一套筛选条件自动成为名为「特征值1」的特征值；原来选「字段筛选特征值」的字段（主映射与拆分映射）自动选中它，输出不变。
- 模板重新导入表头（映射被清空）时，特征值一并清空。
- 模板包导出/导入携带全部特征值与各字段的选择。任一模板用到该值时写 v7，v3.2.17 及更早版本读到 v7 整包拒绝并提示升级；v3.2.16/3.2.17 导出的 v6 包可直接导入，按上一条升级。

## 4. 非目标

- 特征值排序、复制、跨模板共享。
- 新的匹配方式（正则等）。
- 已导出的历史明细不回溯。

## 5. 验收标准

- 选「字段筛选特征值」后右侧出现「选择特征值」、空白下拉框和【特征值管理】；切换为其他值后隐藏。
- 「特征值管理」弹窗：标题与工具栏如 D2；打开时设置区隐藏；【新增】后设置区按 D3 顺序显示；【保存】在【取消】左侧。
- 新增特征值并保存后立即写库，映射行下拉框出现该特征值；选中已有特征值改名保存后，已选它的行显示新名。
- 删除被使用的特征值被拒绝并列出字段；删除未被使用的特征值须先确认，确认后立即写库。
- 两个字段分别选两个特征值时各自筛出对应的值。
- 升级后存量模板的映射与输出不变，特征值名为「特征值1」。
- 模板包导出→导入后特征值与各字段选择一致；v6 包可导入。

## 6. 数据与资金影响

- `templates.feature_filter_json` 改存特征值数组（启动迁移幂等转换旧的单对象）；映射行的特征值选择存于 `mapped_fields_json`；不改其他表结构。
- 新增 IPC `template:save-feature-filters`（preload `templates.saveFeatureFilters`）。
- 模板包按需写 v7。
- 回滚到 v3.2.17：数组形状被旧版读为“尚未设置筛选条件”，用到该值的模板保存与生成被拒绝（失败关闭），不会用旧条件静默输出。
- 不改金额、币种、余额口径；若特征值用于 Credit/Debit Amount、BillDate，按既有规范化与合计行规则处理（v3.2.16 §6）。合计行识别改为取 BillDate 所选特征值的源单元格，须保持“合计金额不作为交易导出”的资金红线。
