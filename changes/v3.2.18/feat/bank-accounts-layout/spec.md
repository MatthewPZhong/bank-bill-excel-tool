# Spec — v3.2.18 设置「账户管理」：按钮移到底栏、表格字段缩减

> status: in-progress
> created: 2026-11-16
> 目标版本：v3.2.18（暂定）
> 适用分支：`feat/bank-accounts-layout`
> 分支创建基线：`v3.2.17` 正式标签 → `a7f268f2`
> 依据：2026-11-16 用户需求与决定（见 §2）；原账户管理需求见 [v3.2.15 账户管理 spec](../../../v3.2.15/feat/bank-account-management/spec.md)，本文替代其 §3 中“表格列为导入时结构的全部列”与“左下角【导入银行账户信息】，其右侧【导出】”两条的布局部分

## 1. 需求

用户原文要点：

- 左下角的【导入银行账户信息】和【导出】按钮下移，与【返回】按钮平行；移动后表格下边界延伸过去。
- 表格字段缩减，只保留：银行/通道简称、开户地、币种、银行账号、系统账号、账户性质、账户状态、是否参与对账。

## 2. 已确认决定

| 编号 | 决定 | 来源 |
| --- | --- | --- |
| D1 | 去掉「行号」列，表格严格只显示上述 8 列，按此顺序 | 用户，2026-11-16 |
| D2 | 翻页条（上一页 / 第 x/y 页 / 下一页）也放进底栏：左侧导入、导出，右侧翻页条，紧挨【返回】 | 用户，2026-11-16 |
| D3 | 【导出】仍按原样另存最近一次导入的原表（含全部列），不受显示列缩减影响（沿用 v3.2.15 D3） | 既有契约 |

## 3. 规则

- 设置底栏新增账户管理槽，只在「账户管理」页显示；版本管理页的【立即检查】组仍只在版本管理页显示。
- 表格宽度铺满表格区域，下边界延伸到底栏上方（保留 16px 间距）。
- 当前识别结构（「设置 → 模板文件 → 清结算银行账户表」）缺少某个显示列时跳过该列，其余列按表头名取值，不错位。
- 可用宽度 ≤ 900px（如 1080 宽 150% 缩放）时，翻页按钮显示为 ‹ ›，隐藏“（共 N 行）”，页码悬停提示保留完整文字；按钮可访问名称仍为“上一页 / 下一页”。
- 导入、导出、翻页、渠道筛选的行为与提示不变；后端读取接口与存储不变。

## 4. 非目标

- 后端 `list` 接口只返回显示列、可配置显示列。
- 账户表对外只读接口（`listAccounts`）的字段。

## 5. 验收

1. 账户管理页：导入、导出、翻页条与【返回】在同一行，导入按钮左缘与表格左缘对齐；切到其他页不显示这些按钮。
2. 表头恰为 8 列且无行号；识别结构缺列时跳过且其余列不错位。
3. 1080×760 明暗主题、1240×860 125%、1080×760 150% 下无溢出，翻页条贴着【返回】（150% 时为紧凑样式）。
4. 原有导入 / 导出 / 翻页 / 渠道筛选的 renderer-lifecycle 用例全部通过。
