## 1. 背景与需求

用户原文要点：

1. **【导入模板】**：用户点击【导入模板】后，如能识别为新模板文件，即弹出框，让用户输入银行渠道名、地区。框的右下角有【确认】和【取消】，【确认】为蓝色。点击【确认】后即保存，模板名 = 银行渠道名 + "-" + 地区。银行渠道名、地区仅支持英文输入，小写在保存时自动转为大写。
2. **余额管理**：
   - 左上角「渠道」单选下拉框右侧新增单选下拉框，默认空白。点击后，下方显示一行输入框，输入框下方列出目标渠道已存余额的账户号。输入框按部分账户号搜索，结果显示在输入框下方。
   - 账户号下拉框右侧有一个短的单选下拉框，选项为目标账户号的币种，默认空白。
   - 余额管理自上而下显示，账期由近到远。

现状：

- **【导入模板】**：选中文件后直接用文件名（不含扩展名）作模板名。同名模板存在时静默覆盖其表头，并清空映射、大账号、固定值、币种大账号与字段筛选。用户手册要求先把文件改名为 `<渠道名>-<开户地>-<其他>`。
- **余额管理**：只有「渠道」下拉。列表按账户号、币种升序排列，同一账号内日期从新到旧。没有按账户号或币种筛选。

## 2. 已确认决策

| 编号 | 决策 | 来源 |
| --- | --- | --- |
| D1 | 银行渠道名、地区只允许英文字母、数字和空格。首尾空格去掉，连续空格合并为一个；不能为空；保存时转为大写。名称按「-」切出银行段与开户地（种子文件、余额附加值、Channel 列、余额账单银行名称与所在地），因此两段内都不能含「-」 | 用户，2026-11-16 |
| D2 | 「银行渠道名-地区」与已有模板（含渠道内子模板）或渠道重名时拒绝，比较时忽略大小写，不覆盖任何数据；弹框保留，可改名重试。同一渠道的另一种格式走渠道行【导入子模板】 | 用户，2026-11-16 |
| D3 | 余额管理按账期从近到远排列，即日期降序；同一天内按账户号、币种升序 | 用户原文 + 默认假设（同日排序） |

## 3. 规则

### 3.1 【导入模板】命名

- **适用范围**：只改主面板【导入模板】。模板管理渠道行【导入子模板】仍按 `渠道名-子模板-N` 自动命名；【导入模板文件】（模板包）不变。
- **选文件与识别**：
  - 点击后弹出文件选择框，可选 xlsx / xls / csv，规则不变；取消则不做任何事。
  - 读取表头（规则与现有导入相同）。文件无法读取或表头无效时，沿用原报错。
  - 「识别为新模板」：表头与所有已有模板都不完全相同。表头重复时提示「该文件的表头与已有模板「X」完全相同，无法创建重复表头的模板。」，不弹命名框。与原规则相比，同名模板不再排除在外。
- **命名弹框**（标题「导入模板」）：
  - 只读显示模板文件名；输入「银行渠道名」「地区」，默认空白。
  - 输入时只保留英文字母、数字和空格，其余字符（中文、符号、「-」）即时去掉；输入法组合结束后再过滤。
  - 右下角【取消】【确认】，【确认】为蓝色主按钮，位于最右。Enter 等同【确认】。
  - 任一项为空时提示「请填写银行渠道名 / 地区」，不提交。
  - 提交期间弹框锁定，不能关闭或重复提交。
- **确认后**：
  - 成功：新建模板「渠道名-地区」（大写），弹框关闭，状态栏提示「已导入模板「X」，请在模板管理中维护映射关系」，模板列表刷新。
  - 名称不合规或重名（D1、D2）：弹框保留，提示原因，可修改后重试。
  - 其他失败（选中的文件在确认期间被修改、导入已失效、文件无法读取）：弹框关闭，状态栏报错，需重新点击【导入模板】。
- **取消**：×、【取消】都不保存，丢弃本次选中的文件。
- **不覆盖**：确认时再次核对名称与表头，导入只会新建模板，不会改动已有模板及其映射。

### 3.2 余额管理：账户号 / 币种筛选

- **头部**：「余额管理」标题右侧依次为「渠道」下拉、「账户号」单选、「币种」单选，后两者默认空白。
- **账户号单选**：
  - 点击后在其下方弹出面板：顶部一行搜索输入框，下方列出当前渠道记录中出现过的账户号（去重、升序）。第一项「全部」，选它回到空白。
  - 输入框按部分账户号搜索，忽略大小写；无结果时显示「无匹配账户号」。
  - 点选后面板关闭，列表只显示该账户号。点击面板外、按 Esc 或再次点击按钮时关闭面板；Esc 只关面板，不关余额管理。
- **币种单选**：选项为空白加所选账户号的币种（升序）。未选账户号时禁用；选了币种后列表只显示该账户号、该币种。
- **联动**：
  - 切换渠道时，账户号与币种都清空。
  - 切换账户号时，币种清空。
  - 修改或删除后列表重新读取：所选账户号或币种已不存在时回到空白，否则保留。
- **列表**：「共 N 条」、分页（每页 200 条）与「暂无余额种子」都按筛选后的记录计算；筛选变化时回到第 1 页并退出编辑。
- **排序（D3）**：日期从新到旧；同一天按账户号、币种升序。
- **不变**：可见范围、修改与删除规则、并发核对、审计口径都与 v3.2.16 相同；筛选只在渲染层进行，不改种子读写。

## 4. 非目标

- 不改【导入子模板】、模板包导入导出、【重命名】的命名规则；已有模板名不迁移、不改大小写。
- 不改余额种子的存放、生成、补录和读取口径。
- 不改余额管理的可见范围与写入接口。

## 5. 假设（低影响、可回退，交付时报告）

- A1：「识别为新模板」按表头不与任何已有模板相同判断，见 §3.1。
- A2：「有余额的账户号」指当前渠道可见的余额种子记录中出现过的账户号，不按余额是否为 0 区分。
- A3：账户号面板第一项「全部」用于回到空白；按钮顺序沿用项目惯例【取消】在左、【确认】在右。

| 编号 | 标准 |
| --- | --- |
| AC1 | 选新模板文件后弹出命名框；右下角【取消】【确认】，【确认】蓝色 |
| AC2 | 输入 `metacomp` / `sg` 确认后新建模板 `METACOMP-SG`；中文、「-」、符号无法输入；`za  bank` 保存为 `ZA BANK` |

| AC4 | 表头与已有模板相同时直接报错，不弹命名框；取消命名不新增模板 |
| AC5 | 选中文件后在确认前被改动时拒绝导入，需重新选择 |
| AC6 | 余额管理头部依次为渠道、账户号、币种；账户号面板可部分搜索，选「全部」复位；币种随账户号联动，未选账户号时禁用 |
| AC7 | 筛选后条数、分页、空提示正确；切换渠道清空筛选；修改 / 删除后筛选按 §3.2 保留或复位 |

## 7. 数据与兼容影响

- 无迁移，主库结构不变。
- 新增 IPC：`template:prepare-import`、`template:discard-import`（只读预检 / 丢弃，TaskPolicy exclude `staging-preflight-only`）。`template:import` 普通导入改为必须带 `importToken`、`bankName`、`region`，归档登记不变（eager 输入，仍归档所选模板文件）。preload `templates` 增加 `prepareImport`、`discardImport`。
- 新模板名决定种子文件 `balance-seeds/<渠道名>.json`、余额附加值文件、明细 Channel 列与余额账单的银行名称和所在地，已有模板不受影响。
