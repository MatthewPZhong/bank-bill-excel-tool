# PR2 公共候选 writer 与混批导入

Goal：按 E5 接通真实 XLSX → 富类型适配 → 单活跃连接的分片候选 → worker 封存 → Main 一次目录提交。基线为 PR1b `6fdde8c2`，原 E5 包保持只读，生产开关保持关闭。

Context：复用 `scanXlsxSheet`、workbook/rels/style 解析、磁盘 SST、financial-decimal 和既有原生线程平台。新增公共同步 SQLite writer，BizOP 为首个调用者，不改造旧 parser pool 或要求其他模块迁入。

Constraints：原件先全部 READY + PREPARE；完整 23/28 列校验后投影 12/9 列；一个文件一个 BU，OP 一个日期，流水允许多日期。金额精确十进制，任一错误整批拒绝，保留来源位置，错误采样截断不停止计数。worker 不发送原始行或错误样本。

用户已明确批准 E01—E03：文本账户保留前导零/长值；数值账户限可信非负整数不超过 15 位、纯零格式可补位；支持 1900/1904 日期与无歧义文本日期，拒绝歧义/时区日期和全数据区公式；无法无损输出的金额用文本。15 位限制不扩大到非键的流水单号，流水单号保留原文本/原 XML 数值词元，不设唯一约束。E03 描述集合、冲突留空和第 14/15 列规则继续作为 PR3 合同。

Done when：公共同步 writer 的所有权/阈值/失败状态有真实 SQLite 证据；真实混批导入、8200+ 行、完整列错误、日期/账号/金额、SST 双限、取消/关闭、后文件失败保留旧目录和来源归属通过。记录小中型资源与 T01 路线比较，独立保留目标规模、Windows 和人工验收。每个完成的本地 PR 随后推送并创建远端 PR，按用户最新授权执行。

## 落地合同

- 单候选写连接，事务 4096 行 / 4 MiB，SQLite `temp_store=FILE` / 16 MiB cache；250000 行 / 256 MiB 为分片目标，索引后记录实际字节。路由、来源项、分片合计最多 4096 项元数据；达到预算报资源错误、完整性为 false，不截断后发布。manifest 仍限 64 KiB，超限同样拒绝。
- 文本日期只按明确的年在前格式 `YYYY-M-D`、`YYYY/M/D`、八位 `YYYYMMDD` 及前两类不带时区时间部分解释；不使用 Date 猜测解析。数值账期必须带可识别的日期格式，General 普通数字拒绝；Excel 1900 虚构日期 serial 60 拒绝；数值小数部分按该序号所属日期归属。投影外非空日期与金额列仍校验。
- 仅同批 SHA-256 完全相同原件的重复选择保留首项。输入指纹为排序后的完整来源内容集合及合同版本，不含本次 artifactId、文件选择顺序或时间；A+B→A+B′ 重读并纳入 A 的业务行。
- Main 先一次结算全部原件；worker 再核对固定原件的实际哈希及读取前后文件身份。大分片的 SQLite/哈希/封存在受资源准入的 worker 内完成。Main 在原 worker 确认关闭后检查返回文档摘要、来源集合、计数和封存文件身份；文件状态改变即拒绝。诊断文件至多 8 MiB，Main 单独复核实际哈希。
- 动态账期候选在创建前写入 task/intent 绑定的 allocation 文档；封存完成前后崩溃都可按完整清单回收。最终 import-commit 文档固定新候选集合和 expectedGeneration，目录事务仍为 PR1b 唯一业务提交点。
- 错误报告独立封存并绑定真实 producer plan/job/session；Main 未登记前退出，恢复 Main driver 会先补登记再处理失败任务。成功时空报告通过真实维护 Task 回收。空 worker 工作目录只在资源关闭后删除；未知/失败内容留给恢复。
- Windows 的目录屏障 unsupported 保持拒绝。支持宿主的完整成功路径和 Windows 拒绝路径分开验证，不能据测试 SKIP 启用功能。
