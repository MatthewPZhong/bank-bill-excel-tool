# Spec — v3.2.16 映射字段「字段筛选特征值」

> status: in-progress
> created: 2026-11-08
> 目标版本：v3.2.16（暂定）
> 适用分支：`feat/mapping-feature-filter`
> 分支创建基线：`v3.2.15` 正式标签 → `5b5caf7b`
> 依据：2026-11-08 用户需求与决策；现有「需要拼接字段」映射（`CONCAT_FIELDS_MAPPING_FIELD`）的适用范围
> 格式来源：`changes/v3.2.16/feat/statement-balance-verification/spec.md`

## 1. 背景

用户需要从原始账单的某一列（如附言）里筛出一段特征值（如流水号 `FT24123456`），填到明细账单的一个或多个字段。v3.2.15 的映射只支持直接取列、「需要拼接字段」和固定值，不能按规则截取一段文字。

## 2. 已确认决策

| 编号 | 决策 | 来源 |
| --- | --- | --- |
| D1 | 映射关系管理的映射字段新增枚举值「字段筛选特征值」，放在「需要拼接字段」下方；可用的目标字段与「需要拼接字段」一致 | 用户，2026-11-08 |
| D2 | 选中后下拉框右侧出现【筛选条件】，打开「筛选特征值」弹窗：单选筛选字段（模板表头）、单选分隔符（空格、`/`、`,`、`.`、`\`）、特征长度、前几位是英文字母、纯数字、输入特征值 | 用户，2026-11-08 |
| D3 | 「输入特征值」= 样例：输入后自动填好特征长度、前几位英文、是否纯数字，用户可再改；运行时按条件匹配，不要求等于样例 | 用户，2026-11-08 |
| D4 | 一个模板只有一套筛选条件：多个目标字段选「字段筛选特征值」时共用，填同一个值；任一行（含拆分/合并映射弹窗）的【筛选条件】编辑的都是这一套 | 用户，2026-11-08 |
| D5 | 前 N 位英文与纯数字可组合：设了 N 时“纯数字”指第 N 位之后全是数字；未设 N 时指整段是数字 | 用户，2026-11-08 |
| D6 | 某行筛不出时该字段留空，导入提示说明未命中行数、报错文件逐行列出；筛出多个时取从左到右第一个 | 用户，2026-11-08 |

## 3. 功能规则

### 3.1 可用范围

- 主映射弹窗：除 Balance、MerchantId、Currency、四个高级字段（按正负号拆分的发生额等）和拆分/合并分组字段外，所有目标字段都可选（与「需要拼接字段」相同）。
- 拆分/合并账单映射关系设置弹窗（「复用模块字段的映射关系」= 否时使用）：除 Currency、Balance 外可选（与该弹窗的拼接口径相同；Credit/Debit 不在该弹窗中）。
- 后端对不允许的目标字段直接拒绝保存。

### 3.2 筛选条件

| 项 | 规则 |
| --- | --- |
| 筛选字段 | 必选，取模板表头（空白表头不列出）；保存时校验仍在表头内 |
| 分隔符 | 下拉：不拆分（整格匹配）/ 空格 / `/` / `,` / `.` / `\`；新建默认“空格”。“空格”按连续空白拆分（含全角空格、不换行空格）；其余按该字符拆分。各段去首尾空白、丢弃空段 |
| 特征长度 | 可空（不限）；整数 1–200 |
| 前几位是英文字母 | 可空或 0（不限）；整数 1–200；英文 = A–Z、a–z，不区分大小写；不能大于特征长度 |
| 纯数字 | 勾选；口径见 D5。设了 N 且勾选时，特征长度须大于 N |
| 输入特征值 | 可空；输入后按 D3 推导并填写上面三项。保存时样例须符合当前条件，且不能含所选分隔符 |

- 特征长度、前几位英文、纯数字至少设一项。
- 输出筛出片段的原文（不改大小写）。

### 3.3 运行口径

- 每个源行只筛一次，所有选「字段筛选特征值」的字段（主映射；「不复用」时为拆分映射）填同一个值，再按各自目标字段的既有规则规范化（日期、金额、MerchantId 账户映射等）。
- 筛不出：字段留空。只为最终有收入或支出的行记录提示（收支均为空的行已有“已过滤”提示）；账单自带的合计行不提示。
- BillDate 选该值时，筛选源单元格整格是合计标签（`合计`、`Total` 等）且带金额的行，仍按账单自带的合计行跳过，不作为交易导出。
  - 导入提示：“N行未筛出特征值，相关字段已留空”。
  - 报错文件：“以下行未筛出特征值，选择「字段筛选特征值」的字段已留空：”，逐行列出 `第N行，源字段“X”，原值“Y”`。
- 模板用到该值但没有有效规则（如旧数据或直接写库）：保存与生成都拒绝，提示“筛选特征值：尚未设置筛选条件，请点击【筛选条件】设置”。

### 3.4 保存与回显

- 有字段选该值但未设筛选条件时，点完成提示“X、Y 选择了「字段筛选特征值」，请先点击【筛选条件】设置”，不保存。
- 规则随映射一起保存；拆分/合并映射弹窗保存时，规则随拆分映射一起写入并回写到主映射弹窗的草稿。
- 规则不再被任何字段使用时保留（再次选用时回显），不影响输出。
- 模板重新导入表头（映射被清空）时，规则一并清空。
- 模板包导出/导入携带规则。任一模板（主映射或拆分映射）用到该值时模板包写 v6，旧版本读到 v6 整包拒绝并提示升级；未用到时仍写 v5，旧版本照常导入。
- 启用拆分/合并且不复用模块映射时，拆分映射用到该值也要求规则有效：保存主映射、导入模板包时缺规则即拒绝。
- 只看实际生效的映射：不复用时主映射里残留的该值不输出，不要求规则、不记未命中提示；保存与生成同一口径。
- 未用到时，弹窗里改过的有效规则也随保存写入（主映射与拆分映射弹窗一致），界面与库不会不一致。

## 4. 非目标

- 一个模板多套筛选规则、正则表达式等自定义规则。
- 全角 `，`、`／` 等与半角分隔符等价处理。
- 已导出的历史明细不回溯。

## 5. 验收标准

- 下拉框中「字段筛选特征值」紧跟「需要拼接字段」；Balance、MerchantId、Currency、高级字段的下拉框中没有该值。
- 选中后右侧出现【筛选条件】，切换为其他值后按钮隐藏。
- 「筛选特征值」弹窗：输入 `FT24123456` 自动填好长度 10、前 2 位英文、勾选纯数字（说明为“前 2 位之后全是数字”）。
- 附言“转账 FT24123456 附言”在上面的规则下筛出 `FT24123456`；“PAY/FT24999999 ZZ12345678 AB87654321”在分隔符为空格时筛出 `ZZ12345678`。
- 两个目标字段选该值时填同一个值；筛不出的行字段留空，导入提示与报错文件如 §3.3。
- 校验：样例不符、样例含分隔符、无条件、未选字段均提示且不关闭弹窗。
- 拆分/合并「不复用」时，只在拆分映射中选该值也能生效；规则随拆分映射保存。
- 模板包导出→导入后规则与映射一致。

## 6. 数据与资金影响

- 新增 `templates.feature_filter_json` 列（启动迁移幂等补列，默认空串）；不改其他表、不改 IPC 通道（`template:save-mappings`、`template:save-bill-split-mappings` 载荷新增可选 `featureFilter`）。
- 模板包：用到该值时写 v6（当前版本支持读取 v6），其余仍写 v5。
- 存量模板不使用该值时输出完全不变、行数不变。
- 若用户把该值用于 Credit Amount / Debit Amount / BillDate，筛出的文字按原金额、日期规则规范化；筛不出时金额为空，该行按“收支均为 0 或空值”过滤并提示。不涉及金额计算口径变化，无资金红线。
