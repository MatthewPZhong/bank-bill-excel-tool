## 1. 背景

用户导入 SCB-SG「账单里的余额」账单（一个账号、六个账单日、近千行，逐笔余额连续），首日弹出「核对上一账单日余额」。真实账单金额不入库，下文示例与回归用例均为同结构的合成数据。

| 现象 | 排查结论 |
| --- | --- |
| 弹窗被截断 | 首日每笔交易一个余额，去重后近 300 个，说明里全部列出；补录弹窗外框 `overflow: hidden` 且说明区不滚动，日期、金额输入框和「完成」按钮被挤出可见区域，无法操作 |
| 收入、预期余额带 `…379999999965`、`…3699999999` 一类长尾数 | 收支累加的浮点尾差。`roundAmountHighPrecision` 按 12 位小数取整，金额到万级以上时超出双精度有效位，去不掉尾差。判定按分比较，结论不受影响；但同一口径下「通过发生额计算」的期末余额会带尾差写入种子，余额表因有效数字超过 15 位降级为文本单元格 |
| 对不上 | 已有种子停在 2026-10-27，账单从 11-02 开始，10-28 ~ 11-01 未导入；种子与账单首行期初余额之差即断档期间净收支。以期初余额为起点，六天逐日校验全部相符。提示不说缺日期，并预填 10-27 的日期，用户只改金额会把 10-27 的正确余额改错 |

## 2. 已确认决策

| 编号 | 决策 | 来源 |
| --- | --- | --- |
| D1 | 核对弹窗的说明区可滚动，日期、金额输入框与「完成」按钮在最小窗口、放大时始终可见可点；账单当日余额超过 6 个时只列前 3 个与后 3 个，并注明共 N 个；活动日志仍完整列出 | 用户，2026-11-10 |
| D2 | 余额计算中的金额加减，结果按参与运算各值的最大小数位（上限 12 位）取整，消除浮点尾差；PRD v1.5.0 的 12 位精度与超过 15 位有效数字转文本的输出规则不变，候选余额按两位小数比较的容差口径不变 | 用户，2026-11-10 |
| D3 | 首日多个余额都对不上、且已有种子日期与首日之间缺日期时：说明写明缺的日期，提示先核对是否漏导这几天的账单，或直接填首日前一天的期末余额（可参考账单期初余额）；弹窗日期预填首日前一天、金额留空。不缺日期时维持 v3.2.16 D7（预填种子日期与金额）。只改提示与预填，校验、路由与种子写入时机不变 | 用户，2026-11-10（调整 v3.2.16 D7 的预填）；金额留空为实现判断，见 3.3 |

## 3. 功能规则

### 3.1 弹窗（D1）

- 补录 / 核对弹窗的正文（账号信息与说明）在空间不足时滚动；输入区与按钮不随之滚走。
- 账单当日余额 ≤ 6 个时全部列出（与 v3.2.16 相同）；> 6 个时写为「（共 N 个）前 3 个 … 后 3 个」，顺序为账单行顺序。
- 活动日志 `formatBalanceSeedMismatchLine` 仍写全部余额，供审计。

### 3.2 金额尾差（D2）

- 适用：「账单里的余额」首日 / 逐日校验的收入合计、支出合计、预期余额、差额；「通过发生额计算」的期末余额；余额附加值累计额，以及余额叠加 / 扣回附加值、人工补录替换差额。
- 加减法的精确结果不会多于参与运算各值的最大小数位，按该位数取整即还原精确值；输入本身带 12 位以上小数时与原 12 位口径一致。
- 合成数据示例：150 笔两位小数收入，旧口径合计 5,126.100000000002、加种子 2,000,000.11 得 2,005,126.2100000002；现为 5,126.10 与 2,005,126.21，发生额计算输出数字单元格。

### 3.3 首日断档说明（D3）

- 判定沿用 `isBalanceDateGap`（种子日期的下一天早于首日）。
- 说明在 v3.2.16 D7 文案后改写结尾：「2026-10-27 与 2026-11-02 之间缺 2026-10-28 ~ 2026-11-01 的账单（只缺一天写该日），请先核对是否漏导了这几天的账单；也可以直接填写 2026-11-01 的期末余额（可参考账单上的期初余额）。」
- 日期预填首日前一天。金额留空：已有种子是更早日期的余额，填在首日前一天名下语义不对，且种子先写后算，错值会落盘。
- 活动日志同一行补写缺的日期。

## 4. 非目标

- 不读取账单里没有收支金额的期初余额行自动作为起点。
- 不改「账单里的余额」逐日校验规则、D6 / D13 及种子写入时机。
- 不改 `roundAmountHighPrecision` 本身（直接映射余额仍按 12 位口径保留）。

## 5. 验收

- 上百个余额的首日核对弹窗，在 1080×760 最小窗口、150% 放大时，输入框与「完成」可见可点，说明区可滚动。
- 同结构合成数据：提示中收支合计与预期无尾差，写明缺 10-28 ~ 11-01，预填 2026-11-01、金额空；填账单期初余额后首日相符。用户的真实账单另做人工回归。
- 「通过发生额计算」同样数据输出数字单元格，无尾差。
- 不缺日期时 v3.2.16 D7 行为与文案不变。
