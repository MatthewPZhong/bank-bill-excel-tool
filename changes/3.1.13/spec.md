## 0. Goal / Context / Constraints / Done when

- Goal：完成工具箱覆盖确认、状态与运行保护，调整存档中心前端，恢复平盘对账数据处理和对账单修复的初始化欢迎文案契约，并移除全部状态框星星 SVG。
- Context：工具箱主弹框与存档中心均由 renderer 动态创建；两个对账模块虽然在 HTML 中显示欢迎文案，但模块进入时的自动状态同步会用历史 session 摘要覆盖它。
- Constraints：不修改 Excel 内容、格式保真、筛选、批次、存档、原子发布或恢复合同；不修改 archiveCenter IPC、数据库查询、统计、迁移、保留期限和维护生命周期；不修改对账 session、金额、币种、匹配、回填、运行结果或按钮判定。
- Done when：全部用户可见行为有定向测试与对应预览证据，两个对账模块的自动同步成功/失败与用户动作状态生命周期符合本 Spec，所有静态及动态状态框均无星星 SVG，相关自动化通过，三份版本资料同步到 v3.1.13。

## 1. 产品行为

### TBX-01 多文件拆分覆盖确认

- 仅作用于“需要拆分成多个文件”模式。
- 用户选定输出目录后，如存在一个或多个同名普通文件，确认框按钮为【返回】/【覆盖全部】。
- 【返回】继续使用 response 0：本次发布取消，不创建、不覆盖任何目标文件，也不预留文件批次。
- 【覆盖全部】继续使用 response 1，沿用既有整批可恢复发布。
- 非普通文件冲突、单文件另存为和合并另存为行为不变。

### TBX-02 状态框结构与几何

- 工具箱主弹框新增状态框，位于“合并表格”与“拆分表格”文本的左侧，并跨两行。
- 状态框左沿与标题“工具箱”左沿对齐。
- 状态框上沿与“合并表格”【导入文件】按钮上沿对齐，下沿与“拆分表格”【导入文件】按钮下沿对齐。
- “合并表格”标签布局宽度保持 72px；状态框外框宽度固定为该宽度的两倍，即 144px。
- 状态框使用项目现有 `status-box` 视觉语言和 `aria-live="polite"`，初始显示“等待操作”。

### TBX-03 状态生命周期

| 流程 | 运行中 | 成功/等待 | 失败 | 用户取消 |
| --- | --- | --- | --- | --- |
| 合并 | 正在合并表格 | 合并完成 | 合并失败 | 已取消合并 |
| 拆分读取 | 正在读取表格 | 等待拆分设置 | 读取失败 | 已取消拆分 |
| 拆分导出 | 正在拆分表格 | 拆分完成 | 拆分失败 | 已取消拆分 |

- 详细成功路径、告警样例和错误明细仍由既有应用内提示框展示；状态框只保留短状态。
- 从选字段弹框返回工具箱，或关闭结果提示后回到工具箱时，显示最近一次状态。

### TBX-04 运行保护

- 合并 IPC、拆分读取 IPC 或拆分导出 IPC 任一进行期间，工具箱右上角关闭按钮隐藏。
- 同期禁用两个【导入文件】按钮，并忽略工具箱遮罩点击关闭，避免运行中关闭或并发启动另一任务。
- 任务完成、失败或取消后，`finally` 统一恢复关闭按钮与两个入口按钮。
- 拆分条件配置期间没有后台工具箱 IPC，关闭按钮行为维持原状。

## 2. 非目标与兼容性

- 不修改 `desktopApi.toolbox` 的方法名或成功/失败结果结构。
- 不修改合并/拆分的输入类型、字段匹配、输出名称、Excel 行数和格式。
- 不新增取消正在执行 worker 的能力；“运行时关闭按钮消失”只约束 UI 关闭与重入。
- 不把【返回】扩展为重新打开已完成的多文件分类编辑器；本迭代只调整覆盖确认框文案并保留无写入语义。
- v3.1.12 及更早版本的存档和输出无需迁移。

## 3. 存档中心前端行为

### ARC-01 日期默认空与初始全量列表

- 每次新建存档中心弹框时，日期选择框默认值为空，不再自动填入当天日期。
- 第一次切换到“存档中心”即使用空 `localDate` 请求批次；模块默认为“全部模块”，批次号为空。
- 批次列表直接展示现有存档中心查询一次返回的全部可见批次，并默认选中返回结果第一条；不再因隐式当天日期只显示当天批次。
- 用户后续仍可选择日期、模块或输入批次号筛选；清空日期后恢复全部日期范围。
- “全量”沿用现有单次查询合同（最多 1000 条），本迭代不新增分页或修改后端上限。

### ARC-02 存档设置入口位置

- 浏览页的齿轮【存档设置】按钮移动到标题文本“存档中心”右侧并直接相邻。
- 按钮的图标、`title`、`aria-label`、点击行为和设置页返回行为不变。
- “文件总大小”继续显示在标题栏右侧，但不再包裹设置按钮。

### ARC-03 存档设置页精简

- 【变更】按钮直接位于“存档位置”文本右侧，不再推到该行最右端。
- 完整存档路径继续在下一行展示，并保留可换行、可选择和迁移进度反馈。
- 设置页移除“存储统计”标题、“文件总大小”、“运行次数”和“最新批次”；保留保留期限、存档位置与迁移状态。
- 浏览页标题栏右侧的“文件总大小”继续显示。
- `getStats()` 及其文件大小、存档路径、迁移状态数据合同不变；文件大小只停止在设置页重复投影。

### ARC-04 顶部提示栏不展示维护类文本

- 首次进入存档中心后，顶部共用提示栏不再显示后台维护的启动、进度、完成或失败文案。
- 后台维护到期删除当前选中批次时，仍清空该选择并刷新详情，但不在顶部提示栏显示维护说明。
- 后台维护的启动时机、执行阶段、失败状态与重试机会不变；维护完成后仍刷新批次列表和文件总大小。
- 列表、详情、存档设置、存档位置迁移、保留期限、文件操作、锁定、删除和重试等非维护操作的提示与错误继续显示。

## 4. 模块初始化状态框行为

### INIT-01 成功初始化保持欢迎文案

- “平盘对账数据处理”和“对账单修复”首次成功加载时，仍读取真实 session、场景、pending run 和按钮可用性，但状态框保持“欢迎使用小助手”。
- 模块切出后再次切回时，自动同步成功不得改写状态框；若当前进程内已有用户导入、运行、导出或选择功能/场景产生的状态反馈，该反馈继续保留。
- VCC 财务 OP 已符合相同契约，本迭代不修改其实现。

### INIT-02 失败可见与动作反馈

- 自动同步返回失败结果或抛出异常时，即使该次同步处于“不更新成功文案”模式，也必须在对应状态框显示读取失败，按钮按无有效 session 的安全状态更新。
- 用户主动导入、运行、导出、确认、切换功能或场景后的状态反馈继续走原有更新路径；本迭代不把状态框永久固定为欢迎文案。
- 本节只调整 renderer 的状态投影时机，不改变任何 desktopApi 参数、数据读取、业务执行、持久化或输出结果。

## 5. 全局状态框装饰

### STATUS-01 移除星星 SVG

- 移除全部状态框中的星星 SVG，包括主页面 13 个静态状态框和工具箱动态弹框的状态框。
- 仓库根部 `Clear/` 当前 UI 样板中的 6 个状态框镜像同步移除星星 SVG，避免样板继续展示已退役结构；冻结的旧版本迭代文档不回写。
- 状态框只保留状态文字；不得保留空的 `.status-spark` 容器、专属图标盒样式或图标与文字之间的 8px 间距合同。
- 状态文字继续在既有状态框内容区域内居中，并保留长文本换行、资金状态框滚动、`data-tone`、`role="status"`、`aria-live` 及点击行为。
- 新开账户状态框继续保持不使用 `.status-box-content` 的既有特殊结构，只删除星星 SVG；不为本需求统一重构状态框 DOM。
- 本项只作用于状态框装饰，不移除按钮、导航、模块切换器或其它功能性 SVG。

## 6. 验收矩阵

1. 工具箱预览中状态框位于左侧、跨两行，四条边界满足 TBX-02，初始文案为“等待操作”。
2. 三类异步流程开始后关闭按钮隐藏、两个入口禁用、遮罩不能关闭；所有终态均恢复。
3. 合并、拆分读取、单文件拆分和多文件拆分分别覆盖 success / failed / cancelled 的短状态。
4. 多文件同名冲突框显示【返回】/【覆盖全部】；选【返回】后临时目录与正式目标均无变化。
5. 工具箱定向单测、集成测试、预览生成和 `git diff --check` 通过。
6. 新开设置弹框并首次进入存档中心时，日期 input 为空，首次 `listBatches` 的 `localDate === ''`，预览中跨多个日期的批次同时出现。
7. 存档设置齿轮紧邻“存档中心”，文件总大小仍位于右侧；【变更】紧邻“存档位置”，完整路径位于下一行。
8. 存档设置页及 renderer 源码不再包含“存储统计”、设置页文件总大小、`archive-stat-runs` / `archive-stat-latest` 投影；浏览页文件总大小、保留期限和迁移行为继续通过测试。
9. 维护启动、进度、完成、失败和维护删除选中批次均不向顶部提示栏写入文本；维护完成刷新与非维护反馈保持可用。
10. 存档中心 browser/settings 双预览、静态合同、运行布局验证和 `git diff --check` 通过。
11. 平盘对账首次成功初始化显示“欢迎使用小助手”；自动同步成功只更新状态与按钮，用户动作摘要不会因切出再切回而消失。
12. 对账单修复自动进入固定使用静默成功同步；历史 session/已选场景不覆盖欢迎文案，用户动作仍使用默认状态更新。
13. 两个模块的状态读取失败结果和 Promise reject 均显示错误；平盘行为回归、两个模块静态接线、主面板布局与预览通过。
14. `index.html` 和工具箱动态模板中的 14 个生产星星 SVG、`Clear/` 当前 UI 样板中的 6 个镜像全部移除；状态框内不存在 `.status-spark` 或 SVG，两套生产主题及样板 CSS 无残余图标盒/gap 合同，状态文字、色调、可访问性和既有几何保持可用。
